# Text-to-BPMN Studio (AI-Powered Workflow Architect)

[English Version](README_EN.md)

Профессиональный инструмент для бизнес- и системных аналитиков. Превращает текстовое описание процессов в семантические BPMN 2.0 диаграммы (User/Service Tasks, Gateways, Orthogonal Routing), валидирует логику через чат и генерирует готовую структуру реляционной БД (SQL).

## Технологический стек
- **Frontend**: React.js 19, Vite, TypeScript, Tailwind CSS.
- **Диаграммы**: bpmn-js (Camunda).
- **Backend**: Node.js, Express.js.
- **ИИ**: OpenAI-совместимый API (Ollama для локальной разработки, OpenRouter для продакшена).

## Особенность архитектуры (Инженерная гордость)
Ключевая инновация проекта — **гибридная генерация**. Мы перенесли расчет тяжелой XML-геометрии (координаты элементов, размеры фигур, точки изгиба стрелок) с плеч LLM на специализированный TypeScript-код (модуль `bpmnBuilder.ts`).

**Что это дает:**
1. **Надежность**: ИИ больше не «ломает» XML-разметку, пытаясь угадать координаты.
2. **Скорость**: Генерация схемы ускорилась до 2 секунд.
3. **Экономия**: Модель выдает только лаконичный плоский JSON-граф (nodes & edges), что снижает потребление токенов в продакшене в 10 раз.
4. **Качество**: Реализована честная ортогональная маршрутизация стрелок — связи больше не пересекают фигуры насквозь.

## Инструкция по локальному запуску (Offline Mode)

Для работы в полностью автономном режиме используется [Ollama](https://ollama.com/).

1. **Установите Ollama** и скачайте модель:
   ```bash
   ollama pull qwen2.5-coder:1.5b
   ```
2. **Настройте окружение**: убедитесь, что в файле `.env` указано:
   ```env
   AI_BASE_URL=http://localhost:11434/v1
   AI_MODEL_NAME=qwen2.5-coder:1.5b
   ```
3. **Запустите проект**:
   ```bash
   npm install
   npm run server   # Запуск прокси-сервера (порт 3001)
   npm run dev      # Запуск фронтенда (порт 5173)
   ```

## Инструкция по деплою в продакшен (Cloud Mode)

Для использования мощных облачных моделей через [OpenRouter](https://openrouter.ai/):

1. **Получите API Key** на OpenRouter.
2. **Настройте переменные окружения** в `.env` или настройках Vercel/Render:
   ```env
   AI_BASE_URL=https://openrouter.ai/api/v1
   AI_API_KEY=your_openrouter_key_here
   AI_MODEL_NAME=anthropic/claude-3.5-sonnet  # или google/gemini-pro-1.5
   ```
3. **Сборка**:
   ```bash
   npm run build
   ```
